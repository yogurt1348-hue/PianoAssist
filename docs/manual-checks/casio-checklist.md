# Короткий чек-лист: проверка на Casio CDP-S110

Отмечать пункты может только Илья после своего прогона. Около 25 минут. После прогона: Настройки → Диагностика → «Сохранить диагностику» и приложить файл.

## Уже проверено автоматически (CI, без пианино)

Эти пункты проверены тестами на сборочной машине и на Linux с виртуальным экраном. На реальном пианино, звуковой карте и Windows они **не** проверены.

- 137 автоматических тестов (Catch2): парсер MIDI, темп, руки, библиотека, настройки, обновления, симулятор практики с управляемыми часами (аккорды в любом порядке, неверные ноты, удержание, повторы, ранние нажатия, долгое ожидание, педаль, темп 50%, режимы рук, конец/пауза/перемотка, петля, отсчёт, потеря MIDI-устройства).
- Сборка Release и Debug под Windows из одного коммита, тесты в обеих конфигурациях, установщик и портативный ZIP, SHA-256, отчёт `windows-checks.txt`.
- Запуск вспомогательного процесса сканирования плагинов (`--scan-plugin`) в CI.
- Выключение дорожки во время игры (тест движка): гаснут только её ноты, позиция и другие ноты на том же канале остаются.
- Окна (главное, настройки, библиотека, «Дорожки и инструменты») открываются и закрываются без ошибок на Linux; скриншоты русского интерфейса просмотрены при 1280×720, 1920×1080 и масштабе 125/150/200%; разделитель перетаскивается, ширина сохраняется.

## Не проверено: нужно пианино и Windows

| # | Шаг | Ожидается | ✓ |
| --- | --- | --- | --- |
| 1 | Установить `setup.exe`; запустить. Потом распаковать portable ZIP в «Документы» и запустить его exe. | Обе версии запускаются. Предупреждение SmartScreen возможно (см. `docs/windows-warnings.md`). У portable данные в `Data\`, у установленной в `%APPDATA%\PianoAssist`. | |
| 2 | Подключить CDP-S110 по USB. | В шапке название пианино и «подключено», ноты и педаль видны в Настройках → MIDI и аудио. | |
| 3 | Открыть MIDI, «Ждать мои ноты», режим «Обе». Сыграть первые 8 тактов, иногда ошибаясь. | Песня ждёт, верная нота проходит даже после минуты ожидания, ошибки видны, позиция не прыгает назад. | |
| 4 | Аккорд взять по одной ноте в разном порядке, медленно (меньше 1,5 с) и очень медленно (больше 1,5 с). | Медленно — засчитан. Очень медленно — попытка сбрасывается, аккорд нужно взять снова. | |
| 5 | Повтор одной ноты: удерживать клавишу; потом отпускать и нажимать. | Удержание не проходит следующую такую же ноту, каждое новое нажатие проходит. | |
| 6 | Поставить A и B (перетащить флажки на линейке), включить петлю и отсчёт, темп 70%. | Перед стартом и каждым повтором один такт отсчёта. На B возврат к A без висящих нот. Педаль в диапазоне восстанавливается после возврата. | |
| 7 | Правая рука / левая рука, «Играть другую руку» и «Сопровождение» вкл/выкл. | Приложение играет другую руку и группу, ждёт только выбранную. | |
| 8 | Во время ожидания выдернуть USB, подождать, вставить обратно, сыграть ноту. | Сообщение об отключении; после подключения песня продолжает с той же ноты. | |
| 9 | Выбрать VST3 (или SoundFont) для дорожки, открыть и закрыть его окно 5 раз, поменять пресет. Сменить частоту в Настройках → MIDI и аудио (44,1 ↔ 48 кГц). Закрыть и снова открыть песню. | Звук продолжается после смены частоты; пресет и звуки дорожек восстановлены. | |
| 10 | Файл → Библиотека композиций (Ctrl+B): открыть песню из списка; «Убрать из библиотеки» для другой. | Настройки песни восстанавливаются. После удаления исходный MIDI на месте. | |
| 11 | Задержка: Настройки → MIDI и аудио → «Измерить задержку», нажимать любую клавишу на каждый щелчок (14 щелчков), «Применить». Потом сыграть знакомый кусок с ожиданием. Повторить на настоящих колонках/проводных наушниках вместо SteelSeries Sonar и в режиме «Windows Audio (Low Latency Mode)». | Результат около стабильного значения (разброс до ~40 мс). После применения песня больше не встаёт на каждой ноте; в журнале «Practice timing» медиана близка к 0, «stalls» мало. | |
| 12 | Установить новый `setup.exe` поверх, запустить. | Настройки, библиотека и звуки на месте. | |
| 13 | Помощь → «Проверить обновления». | Показывает текущую или более новую версию, ничего не устанавливает. | |
| 14 | Во время игры с сопровождением: окно «Дорожки и инструменты», выключить (Mute) звучащую дорожку, потом Solo другой, снять Solo. | Гаснет только выключенная дорожка, без зависших нот; остальные, в том числе на том же канале и инструменте, звучат дальше; песня не останавливается. Требования практики не меняются. | |
| 15 | Во время игры сменить роль дорожки (например, на «Исключена из практики»). | Воспроизведение продолжается с той же позиции, без висящих нот; исключённая дорожка не звучит и не проверяется. | |
| 16 | Остановиться на ожидании нот, затем снять «Ждать мои ноты». | Песня продолжает с текущего места, без скачка и без пачки пропущенных нот. Табличка вверху меняется на «Свободное воспроизведение». | |
| 17 | Перетащить разделитель панели, свернуть и развернуть её, двойной щелчок по разделителю. Перезапустить приложение. | Ширина и состояние панели сохранились; двойной щелчок возвращает стандартную ширину. | |
| 18 | Окно дорожек: растянуть, развернуть, закрыть, открыть снова. Если есть второй монитор — перенести туда, закрыть приложение, отключить монитор, запустить. | Открывается одно окно на прежнем месте; без второго монитора — на видимом экране. | |
| 19 | Кнопки −/+, «Вся композиция», «К текущей позиции»; во время игры прокрутить пианоролл колесом. | Масштаб сохраняет текущую позицию; ручная прокрутка не сбрасывается сразу, «К текущей позиции» возвращает слежение. | |
| 20 | Настройки → Диагностика → «Путь MIDI-ввода». Нажимать клавиши Casio: до открытия композиции, после открытия, во время игры, в режиме ожидания, после открытия и закрытия настроек и окна дорожек, после смены звука. | Строка состояния: «найден · открыт · события поступают». Счётчики «Получено callback», «в очереди», «обработано окном» и «обработано практикой» растут вместе, «потеряно» остаётся 0. | |
| 21 | Там же нажать «Проверить путь ввода». | Появляется нота C4, все счётчики увеличиваются на 2. Если тестовая нота проходит, а клавиши Casio нет, события не приходят от устройства или драйвера. | |
| 22 | Выдернуть USB, подождать 3 с, вставить обратно. Затем закрыть PianoAssist и сразу запустить снова. | После переподключения вход открывается сам. Если Windows не даёт открыть вход, видна причина «не открыт» с пояснением, а не «Подключено»; попытка повторяется каждые 5 с. | |

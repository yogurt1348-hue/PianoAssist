# Утренняя проверка: фазы 3.1, 4, 5, звуки и финальная фаза

Одна сессия примерно на 30–40 минут на Windows с подключённым CDP-S110 (USB TO HOST). Пункты, отмеченные «подробно», расписаны по шагам в отдельных файлах. После проверки приложите лог: **Diagnostics... → Save report** (папка пользователя в отчёте скрыта).

Ставить «готово» по пунктам может только Илья после своего прогона.

## 0. Установка

| # | Шаг | Ожидается |
| --- | --- | --- |
| 0.1 | Скачать `PianoAssist-windows-x64-setup.exe` из последнего test-build и установить. | Установка без прав администратора; ярлык в меню «Пуск». SmartScreen может предупредить: «Подробнее → Выполнить в любом случае». |
| 0.2 | Альтернатива: распаковать Release ZIP и запустить `PianoAssist.exe`. | Запускается без установки каких-либо компонентов VC++. |
| 0.3 | Окно на 200% масштабе Windows. | Окно помещается в экран, кнопки не наезжают друг на друга. |

## 1. Тайминг, табло и клавиатура (фаза 3.1, подробно: `phase-3-practice.md`, шаги 13–18)

| # | Шаг | Ожидается |
| --- | --- | --- |
| 1.1 | Practice включено, «Normal timing», играть чуть раньше или позже. | Нажатия засчитываются, песня идёт дальше без остановок. |
| 1.2 | «Strict timing» и «Easy timing». | Strict строже, Easy прощает заметные промахи по времени; выбор запоминается после перезапуска. |
| 1.3 | Табло PLAY NEXT. | Крупные ноты с названием и до/ре/ми, левая рука оранжевая, правая синяя, дальше «then». При остановке — жёлтое WAITING FOR YOU. |
| 1.4 | Клик мышью по клавишам, протянуть по нескольким. | Каждая клавиша звучит, пока зажата, и подсвечивается синим; после отпускания ничего не тянется. |
| 1.5 | Быстрый пассаж в Practice. | Позиция никогда не прыгает назад, песня не замирает после верного нажатия. |

## 2. Режимы и аккомпанемент (фаза 4, подробно: `phase-4-modes.md`)

| # | Шаг | Ожидается |
| --- | --- | --- |
| 2.1 | Песня с группой и двумя руками; «Right hand», «Play other hand» и «Play backing» включены. | Приложение играет левую руку и группу, ждёт только правую руку. |
| 2.2 | Выключать по очереди «Play other hand» и «Play backing». | Пропадает соответствующая партия, остальное играет. |
| 2.3 | Песня со вступлением без пианино. | Вступление играет без остановки, табло пишет «Accompaniment only». |
| 2.4 | Поменять руку у партии с «?». | Цвета и ожидание меняются сразу, позиция сохраняется. |

## 3. Звуки (SoundFont и VST3)

| # | Шаг | Ожидается |
| --- | --- | --- |
| 3.1 | Sound → «Load SoundFont...» и выбрать бесплатный `.sf2` (например GeneralUser GS из `docs/sounds.md`). | Пианино и остальные инструменты звучат своими тембрами, барабаны на канале 10 слышны. |
| 3.2 | Sound → «Scan for VST3 instruments» (если установлен хотя бы один VST3-инструмент, например Spitfire LABS или Keyzone Classic). | Инструменты появляются в списке; выбор одного играет его звуком. |
| 3.3 | Кнопка «Instrument...». | Открывается окно плагина; изменения в нём слышны. |
| 3.4 | Перезапустить приложение. | Выбранный звук и настройки плагина восстановлены. |
| 3.5 | Переключать звук во время воспроизведения. | Нет щелчков с зависшими нотами, нет вылета. |

## 4. Финальная фаза: новый вид и вкладка «Other tracks»

| # | Шаг | Ожидается |
| --- | --- | --- |
| 4.1 | Общий вид. | Тёмная тема, блоки в скруглённых панелях: вход MIDI, песня и практика, партии с роллом, табло, клавиатура. |
| 4.2 | Открыть песню с группой (бас, барабаны, струнные). | На вкладке «Practice» только партии пианино; вкладка называется «Other tracks (N)». |
| 4.3 | Перейти на «Other tracks» (клик или Ctrl+Tab). | Список дорожек с инструментом (General MIDI) и числом нот, свой ролл только с этими дорожками. |
| 4.4 | Снять галочку у одной дорожки во время воспроизведения. | Дорожка замолкает, остальное продолжает играть с того же места. |
| 4.5 | Переназначить дорожку из «Other tracks» в «Right hand». | Она переходит на вкладку «Practice», и приложение ждёт её ноты. |
| 4.6 | Узкое окно (около 800 px). | Строка со звуком переносится вниз, ничего не перекрывается. |

## 5. Выпуск (фаза 5)

| # | Шаг | Ожидается |
| --- | --- | --- |
| 5.1 | Ctrl+O, Ctrl+P, Ctrl+1/2/3, Ctrl+T, пробел, Esc. | Открыть файл, Practice, режимы, тайминг, Play/Pause, Silence. |
| 5.2 | Diagnostics... → Copy и Save. | Отчёт с версией, звуком и последними строками лога; имя пользователя заменено. |
| 5.3 | Открыть MIDI-файл, поиграть, закрыть приложение. | Сам MIDI-файл не изменён (дата изменения та же). |
| 5.4 | Отключить USB во время игры и подключить обратно. | Баннер «Piano disconnected», затем автоматическое подключение; ноты не зависают. |

Ограничения, о которых известно заранее: `docs/known-limitations.md`.
